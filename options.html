PORTABILITY

Backups

Export your assignments or restore a trusted JSON backup. Imports match containers by unique name, so create matching containers in the destination profile first.

Credentials are excluded by default. Including them creates a file with plain text secrets. After restoring a backup without credentials, re-enter them before browsing.

PRIVACY

What is protected

  • Assigned proxies have no fallback to a direct connection.
  • SOCKS5 uses remote DNS for supported requests.
  • HTTP proxy credentials are sent only for verified proxy challenges.
  • No analytics, remote scripts, or browsing logs.

Proxy settings and credentials are stored locally in your Firefox profile. The extension does not encrypt them. Protect your profile and backup files.

Default, private, unassigned and paused containers use Firefox’s existing routing. WebRTC and traffic outside Firefox’s proxy API are outside this extension’s protection. Your proxy provider can observe traffic routed through it.

GETTING STARTED

One route per container

  1. Create containers using Firefox’s new tab button.
  2. Assign a protocol, host and port to a container above.
  3. Open a new tab in that container and verify its connection.

HTTPS encrypts the connection to the proxy. SOCKS5 supports remote DNS but does not encrypt the proxy transport by itself.

For a local Gluetun HTTP proxy, use the reachable host or published address and port, such as 127.0.0.1:8888. Choose credentials configured on your proxy.
